# Дизайн: Spirits, Snotty Bat (Task 25)
## Архитектура
- **Пул спутников** `Run.Companions.cs` (новый partial, по образцу `Run.Ground.cs`): `Companion[] Companions`, `ActiveCompanions`, стек свободных слотов, `SpawnCompanion(OwnedPowerUp source, Vec2 position)` → `Companion` или null (`pool:companions` один раз), `RetireCompanion`, `UpdateCompanions(dt)`, `SnapshotCompanions()` и `ResetNewCompanions(int serial)` для интерполяции. В `Run.cs` — 4 строки: создание пула в конструкторе, `SnapshotCompanions()` и `ResetNewCompanions(serial)` в `FixedStep`, `UpdateCompanions(dt)` в `Tick` после `UpdateGroundObjects`.
- **Сущность** `Companion` (`World/Entities.cs`): `Slot`, `SpawnId`, `Active`, `Source`, `Body` (`EnemyDef`, у мыши — `snotty`, у духа — null), `Position`, `PreviousPosition`, `Direction` (для поворота модели), `Angle` (радианы, `double`), `Age`, `Life`, `Timer`, `Born`, `Radius`, снимок удара (`Damage`, `DamageType`, `DamageFlags`, `DamageSource`, свойство `Hit`), `HitMarks` — `int[Rules.MaxEnemies]`, где по слоту врага лежит `SpawnId` поражённого (очистка `Array.Clear` при создании, без выделений).
- **Интерфейс** `ICompanionAbility` (`Abilities/Abilities.cs`): `bool UpdateCompanion(Run run, Companion c, float dt)` — false, когда спутник кончился. Пул вызывает его каждый шаг, также при упавшем герое; сама способность решает, что делать при `run.Downed`.
- **События** `SimEventKind.CompanionSpawned` / `CompanionEnded` (Slot, SpawnId, Position, Value = ID способности) через перегрузку `Emit(kind, Companion, position)` в `Run.Events.cs`. Удары — существующий `AbilityBurst` (`Run.EmitBurst`).
- **Обработчики:** `Abilities/Spirits.cs` (`Spirits : AbilityBase, ICompanionAbility`), `Abilities/SnottyBat.cs` (`SnottyBat : AbilityBase, ICompanionAbility`); строки в `AbilityFactory`. Поиск врагов — `CircleTargets` (свой буфер, `SpawnId`, урон после закрытия запроса); `CircleTargets.Any` для проверки цели.
- **Подбор мышью:** в `Run.cs` приватный `Collect(Pickup)` получает обёртку `internal void CollectPickup(Pickup p)` (одна строка) или переименовывается в `internal`; обход пула предметов — в `SnottyBat`, без сетки (как `UpdatePickups`).
- **Почему не пул врагов для мыши.** Определение `snotty` лежит среди врагов, и пул врагов умеет дружественных (колонны). Но враг в пуле участвует в расталкивании соседей (запрос сетки в `UpdateEnemies` не смотрит слой), в отталкивании при уровне (`LevelUpKnockback` берёт всех активных), в счёте `ActiveEnemies` и пределе пула орды, а движение `STATIONARY` пришлось бы подменять. Отдельный пул не трогает правила орды; определение `snotty` используется как тело мыши: скорость, модель, масштаб.
- **Представление** (`WorldRenderer.Draw`): цикл по `run.Companions`; положение `run.Interpolate(PreviousPosition, Position)`. Дух — бело-голубая сфера диаметром `2 × SpiritRadius` на высоте 0.8; мышь — запечённый облик `looks["snotty"]` (клип `run`, масштаб `HeroView.ModelScale × 0.75`, поворот по `Direction`), без облика — зелёная сфера. Состояние по слоту между кадрами не хранится, поэтому сверка `SpawnId` не нужна (как у наземных объектов); события несут `SpawnId` для будущих эффектов (Task 37). Чистая функция `CompanionPoint(Run, Companion)` для EditMode-теста.

## Данные
Числа — из `owned.Local`/`Build.Stat` по общему пути (`AbilityBase`). Поля определения вне атрибутов: `m_flRotationSpeedDeg`, `m_flRotationDist` — через `DataField` (нет поля — диагностика `ability:snotty_bat:<поле>`, 0). Тело мыши — `Data.Enemies["snotty"]`, ключ берётся из `m_sSource` определения способности; нет такого врага — диагностика `ability:snotty_bat:m_sSource`, мышь не создаётся. Скорость мыши — `EnemyDef.MoveSpeed` (650).

## Правила (метки для Mechanics §32)
### Пул
- **Р1. Пул `Companion`** — `Rules.MaxCompanions` = 32, общий. Оценка: Spirits ранга 9 у Dragonus — 6 духов на 6 с (+1 с Timeless Relic), при перезарядке 5 с — до 12, с глобальным сокращением 0.5 — до 18; мышь 1 (Aghanim — 2, Task 27); с постоянной прокачкой `TargetCount` +2 — до 26.
- **Р2. Переполнение:** нет слота — спутник не создаётся, перезарядка всё равно начинается, `pool:companions` один раз за забег; живые не вытесняются (как §31 Р2).
- **Р3. Обновление** в шаге после наземных объектов, также при упавшем герое; спутник не обновляется в шаге создания (`Born`). Пауза, выбор и конец забега останавливают шаг целиком. Спутник без обработчика сразу заканчивается.
### Spirits
- **Р4. Призыв** по перезарядке без проверки врагов (как Land Mine, §31 Р4), первый — сразу после получения; перезарядка — с призыва; призывы накладываются.
- **Р5. Длительность** `Duration + DurationExtension` (Timeless Relic +1 с). Закрывает §25 Р5 для Spirits. Общее правило: собственная `Duration` способности продлевается, если в определении есть `DurationEffect` 1 (Stampede — решение владельца 12.11.2026, Spirits); у Land Mine `DurationEffect` нет, её `LifeTime` не продлевается (§31 Р5).
- **Р6. Круг.** `TargetCount` духов (Dragonus +1) с углами `θ₀ + 2πk/N`, `θ₀` — угол `Run.Facing` при призыве; радиус — `Range` 350 без `AoEIncrease` (это расстояние, а не область). Центр — текущее положение героя на каждом шаге: духи идут вместе с героем. Духи появляются сразу на круге.
- **Р7. Вращение** `Spirits.RotationSpeedDeg` = 180°/с против часовой (оборот за 2 с, касательная скорость ≈ 1100 ед./с, 37 ед. за шаг). Скорости в данных нет; 45°/с мыши для «танца» духов медленно.
- **Р8. Касание.** Круг духа `Spirits.SpiritRadius` = 50 (как снаряд Magic Missile; радиуса в данных нет). Враг поражён, если `|e − c| ≤ 50 + e.Radius`. Каждый дух бьёт каждого врага не больше одного раза за жизнь (`HitMarks` по слоту врага и `SpawnId`); разные духи бьют независимо. Урон магический, не снаряд (нет `ProjectileAttack`): `Projectile_BonusMagicDamage` и криты снарядов не действуют, ослабление Shen срабатывает.
- **Р9. Взрыв** в шаге, где `Age ≥ Life`: `AbilityBurst` (центр духа, радиус, `Value` 210), затем урон по одному разу всем поражаемым врагам, чей круг касается круга `Radius × (1 + AoEIncrease)`; тот же урон, что у касания (второго числа урона в данных нет). Касание в шаге взрыва не проверяется.
- **Р10. Снимок** урона, радиуса взрыва, длительности и радиуса круга — при призыве.
### Snotty Bat
- **Р11. Тело** — враг `snotty` (ID 400) по `m_sSource` (**Д**: общий суффикс класса, источник, портрет). Мышь не враг: не цель, не препятствие, не расталкивается, не получает урона, летает над пропастями и стенами, по границе карты не ограничивается.
- **Р12. Появление** — один спутник на способность, в первом шаге после получения, в положении героя; при полном пуле — попытка каждый шаг. Живёт до конца забега; если способность пропала (обработчика нет), спутник кончается (Р3).
- **Р13. Полёт.** Точка орбиты `герой + 700 × (cos φ, sin φ)`, `φ` растёт на `m_flRotationSpeedDeg` 45°/с (оборот за 8 с), начальный `φ` — угол `Facing` при появлении. Мышь каждый шаг смещается к точке орбиты не больше чем на `650 × dt` (`m_flMoveSpeed` тела): при стоящем герое касательная скорость орбиты 550 < 650 и мышь держится на ней; при беге героя или телепорте отстаёт и догоняет. `Direction` — направление последнего смещения.
- **Р14. Удар** по истёкшей перезарядке (допуск полшага, §30 Р2), если круг поражаемого врага касается круга `Radius × (1 + AoEIncrease)` вокруг мыши (§28 Р1); иначе проверка каждый шаг (как Counter Helix, §28 Р5). Перезарядка — с удара. Центр — мышь, а не герой (`m_eOrigin` `PLAYER_ORIGIN` прочитан как центр вращения).
- **Р15. Попадание:** `AbilityBurst` (центр, радиус, `Value` 22), физический урон по одному разу, затем замедление выживших с тем же `SpawnId`: `Run.Slow(SlowStrength, SlowDuration + DurationExtension)` (§24 Р8–Р9, §25 Р5). Не снаряд: `BonusPhysicalDamage` действует, криты снарядов — нет; физический крит Crystalys действует. Отталкивания нет (в данных нет `KnockbackDistance`).
- **Р16. Подбор.** Каждый шаг мышь подбирает каждый активный предмет на расстоянии центров ≤ собственного `PickupRadius` способности (50, `owned.Local`, без радиуса подбора героя 250). Подбор — то же действие, что у героя (`Collect`): опыт, лечение, золото, магнит, сокровище. Предмет не летит к герою.
- **Р17. Упавший герой** (§25 Р8): мышь летает, не бьёт, не подбирает; перезарядка не идёт (способность не тикает).
### Общие
- **Р18. События** `CompanionSpawned` / `CompanionEnded` с `SpawnId`; касания духов дают только `EnemyDamaged`.
- **Р19. Роль `snotty` в реестре** — `summon` (**Д**: враг, чей класс делит суффикс с классом способности, призывается ею; это правило уже даёт ссылку `powerups/snotty_bat → enemies/snotty`). Уровень реализации такого врага равен уровню способности. Таблица §1: «1 дружественный, 1 призыв».
- **Предложение.** Обе способности реализованы и предлагаются при уровне всем героям; выбор улучшений у прежних seed изменится.

## Решения владельца (12.11.2026, ответ «дальше» — приняты все предложенные варианты)
1. Радиус подбора мыши — только собственный `PickupRadius` 50, без радиуса героя (Р16).
2. Касание духов — каждый дух бьёт врага один раз за свою жизнь, разные духи независимо (Р8).
3. Вращение духов 180°/с и радиус касания 50 (Р7, Р8).
4. Удар мыши — только при враге в круге вокруг мыши, иначе ожидание (Р14).
5. Отдельный пул спутников вместо пула врагов (Р1).
6. `DurationExtension` продлевает `Duration` Spirits по правилу `DurationEffect` 1 (Р5).
7. Роль `snotty` в реестре — `summon` (Р19).

## Вопросы владельцу (решения **Р**, которые меняют игру; закрыты, см. выше)
1. Радиус подбора мыши: только свои 50 (предлагается) или `50 + PickupRadius героя` (300, по общему правилу `Stat = Local + Global`).
2. Касание духов: каждый дух бьёт врага один раз за жизнь (предлагается) или весь призыв бьёт врага один раз.
3. Скорость вращения духов 180°/с и радиус касания 50 — числа без данных.
4. Удар мыши только при враге в круге (предлагается) или по перезарядке всегда.
5. Пул спутников вместо пула врагов для мыши (обоснование выше).

## Риски
- Числа Р7, Р8, Р13 меняют темп игры; при наблюдении в клиенте меняются константами `Spirits.RotationSpeedDeg`, `Spirits.SpiritRadius`.
- Мышь собирает опыт на орбите 700: прокачка ускорится; это и есть смысл способности по описанию.
- `HitMarks` на 32 слота × 1024 int = 128 КБ при создании забега — в пределах бюджета памяти, вне шага.
- Smoke: герой стоит, мышь бьёт врагов, проходящих через орбиту 700; ожидание попаданий до `SmokeForce.MaxSeconds` 65 с уже есть.
